# Pulse UI Consistency Rule

For every new Pulse update or addition, reuse the existing in-app Pulse visual system by default.

- Match the existing module spacing, max-width, alignment, card rhythm, typography scale, heading size, body text size, button sizing, badges, and responsive breakpoints.
- New screens inside the authenticated Pulse app should visually align with current modules such as My Feed, People, Resources, Opportunities, Career Readiness, Mentorship, Stars, and Invite.
- Do not introduce larger hero typography, experimental spacing, new color themes, or different layout proportions unless explicitly requested.
- When adding a new page, include it in the existing `.pulse-app-site` responsive and page-width rules instead of creating a separate visual scale.
